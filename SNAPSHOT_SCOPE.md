# Offline snapshot scope

This source snapshot derives from the pinned Uranius checkout documented in the local test report. CANDIDATE_MANIFEST.csv classifies every tracked source path. Export paths and SHA-256 checksums are supplied for included inherited files. SNAPSHOT_SHA256.csv covers the complete local payload apart from itself.

The snapshot includes the game frontend, lockfile, Node build tooling, local visual assets, game and race-engine code, and inactive schema references. The database is disabled until a separate sandbox is configured. Source recovered from locally available history and verified GitHub pins is described by the manifests under reference/.

Inherited release automation, hosting configuration, worker entry points, job and admin scripts, database connection metadata, legacy SQL archives, history, generated test output and cache files stay outside the draft. Raw historical data seeds are withheld. Retained schema definitions are review references with a .txt suffix. They are not a deployable migration set. Synthetic sandbox seed data is scheduled separately.

The historical 96-rider diagnostics and their test fixture remain quarantined after sporting equivalence could not be verified. The offline two-rider stage checks deterministic shadow execution, replay adaptation and classification comparison. The larger historical workload is still a coverage gap.

The public upload remains subject to owner review and completion of the safety milestone.
